## Meff Library 📚

Meff Library is a modern and interactive platform for managing digital book collections, connecting readers with their favorite books, and providing a seamless browsing experience.

## 🚀 Features

- 📖 **Book Catalog** – Browse and search books effortlessly  
- 🔍 **Advanced Search** – Filter by category, author, and rating  
- 📚 **User Library** – Save and manage personal book collections  
- 🎨 **Modern UI** – Sleek and responsive interface  
- 🛠️ **Vendor Dashboard** – Manage book listings, analytics, and sales  

## 🔧 Installation

1. Clone the repository:
   ```sh
   git clone https://github.com/RemedyOnline/meff-library-app.git
   cd meff-library-app
   ```

2. Install dependencies:
   ```sh
   npm install
   ```

3. Start the development server:
   ```sh
   npm run dev
   ```
